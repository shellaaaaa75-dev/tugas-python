Tugas Praktik Python Dasar

Repository ini berisi kumpulan hasil praktik pemrograman Python Dasar dari Bab 1 sampai Bab 11 yang dikerjakan menggunakan Visual Studio Code (VS Code).

Materi Praktik

1. Bab 1: Pengenalan Python
2. Bab 2: Variabel dan Tipe Data
3. Bab 3: Input dan Output
4. Bab 4: Operator
5. Bab 5: Percabangan
6. Bab 6: Perulangan
7. Bab 7: List, Tuple, Set, dan Dictionary
8. Bab 8: Function
9. Bab 9: Error Handling
10. Bab 10: Module dan Package
11. Bab 11: Pengolahan Data dan Mini Project

Tujuan Praktik

Memahami konsep dasar pemrograman Python serta menerapkannya melalui berbagai contoh program sesuai materi pembelajaran.

Tools yang Digunakan

- Python 3
- Visual Studio Code
- Terminal
- Library Pandas
- GitHub

Cara Menjalankan Program

1. Unduh repository ini.
2. Buka folder proyek menggunakan VS Code.
3. Pastikan Python sudah terinstal.
4. Instal dependensi dengan perintah python -m pip install -r requirements.txt.
5. Jalankan file Python yang ingin diuji, misalnya python hello.py atau python main.py.

Untuk program pengolahan data, file nilai.csv harus berada di folder proyek yang sama dengan program pembacanya.

Keterangan

Setiap file Python berisi contoh praktik berdasarkan materi yang dipelajari. Folder utils berisi modul tambahan yang digunakan dalam praktik Module dan Package.

Repository ini dibuat sebagai dokumentasi dan pengumpulan tugas praktik Python Dasar.
